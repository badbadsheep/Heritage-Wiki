# 大洋洲

<p class="lede">太平洋上最辽阔的一片海域，在联合国名录上的身影却最为稀少——这恰恰提醒我们：名录能留住的，从来只是世界非遗的一角。</p>

| 国家 / 地区 | 项目 | 年份 | 说明 |
| :-- | :-- | :--: | :-- |
| 瓦努阿图 | 沙画 | 2008 | 一根手指，一幅「不能保存的杰作」 |
| 汤加 | 拉卡拉卡歌舞 | 2008 | 数百人同声的群岛之舞 |

<div class="admonition note">
<p class="admonition-title">为什么这么少？</p>
<p>太平洋岛国的非遗丰富多彩——独木舟技艺、导航术、纹身传统、树皮布与编织……但受申报能力、资源与机制语言所限，大洋洲在联合国名录中的项目数量长期偏少。近年来，教科文组织与各国正推动更多太平洋社区走上名录——名录的多样性，本身就是文化多样性的一部分。</p>
</div>
