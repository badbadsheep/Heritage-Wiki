## 一、本志是什么

**非遗志（HeritageWiki）** 是一部以「门类—子类—词条」逐层展开的**非物质文化遗产图文百科**，本体为一个可离线运行的静态站点（MkDocs + Material 构建），全部内容以 Markdown 撰写、可自由编辑与再发布。

- **中国卷**：国务院公布的**五批国家级非物质文化遗产代表性项目名录（共 1557 项、3610 个子项）逐项立档**；十大门类各设门类导航页、子类门览页、项目名录总表；代表性项目撰写多图深度专题；每一门类择一位匠人立传。
- **世界卷**：联合国教科文组织（UNESCO）名录机制、中国入选项目全录、五大洲代表项目巡礼。

## 二、内容体系（五级层层展开）

| 层级 | 页面 | 形态 | 入口 |
| :-- | :-- | :-- | :-- |
| 1 | 首页 | 半透明大图 + 门类气泡 | `/` |
| 2 | 总览页（中国非遗 / 世界非遗） | 大图 + 十门类气泡 + 速览表 | 首屏按钮 |
| 3 | 门类导航页（如「传统美术」） | 大图 + 子类气泡 + 专题/人物/名录入口 | 总览页气泡 |
| 4 | 子类门览页（如「剪刻与雕塑」） | 全部项目以气泡铺陈 | 门类页气泡 |
| 5 | 项目词条页（如「剪纸」） | 五段图文 + 图版 + 子项表 | 任意一层 |

> 侧栏（左侧目录）始终呈现「中国非遗 → 门类 → 子类 → 词条」的完整嵌套；每一词条页顶部另有「分类栏目」（面包屑 + 同门类链接），层层可溯。

## 三、名录数据

- **数据来源**：国务院公布的《国家级非物质文化遗产代表性项目名录》第一批至第五批（含各批扩展项目），经**中国非物质文化遗产网·中国非物质文化遗产数字博物馆（ihchina.cn）**公布数据整理校核。
- **校验结果**：本站收录 **1557 个项目编号**（即官方"1557 项"）、**3610 条子项记录**，各批次数量与国务院公布数量逐一吻合：

| 批次 | 公布时间 | 主项目数 | 本站收录 |
| :-- | :--: | :--: | :--: |
| 第一批 | 2006 年 | 518 | 518 ✓ |
| 第二批 | 2008 年 | 510 | 510 ✓ |
| 第三批 | 2011 年 | 191 | 191 ✓ |
| 第四批 | 2014 年 | 153 | 153 ✓ |
| 第五批 | 2021 年 | 185 | 185 ✓ |
| **合计** |  | **1557** | **1557 ✓** |

- **编号体系**：项目编号以罗马数字前缀区分十大门类——**Ⅰ 民间文学、Ⅱ 传统音乐、Ⅲ 传统舞蹈、Ⅳ 传统戏剧、Ⅴ 曲艺、Ⅵ 传统体育·游艺与杂技、Ⅶ 传统美术、Ⅷ 传统技艺、Ⅸ 传统医药、Ⅹ 民俗**；每个编号即本志一个词条，其下子项（括号变体、各地扩展）于词条内「子项一览」尽录。

## 四、图片体系

每篇词条**至少 5 张高清 PNG 配图**，来自两个体系：

1. **图版**（自绘）——「题名 · 山川 · 纹样 · 工巧 · 名录」五式，按门类色谱与器物意象绘制，全站统一视觉语言；
2. **实景大图**（AI 生成）——用于页面顶部的**半透明大背景**与专题配图。

> 说明：实景大图为 AI 生成的**意临之作**，用于呈现气氛，**并非所涉手艺的纪实影像**；纪实影像请以博物馆、官方影像数据库为准。

## 五、编纂分级（诚实说明）

| 分级 | 范围 | 内容 |
| :-- | :-- | :-- |
| 深度专题 | 十门类代表项目（当前 12 篇 · 持续扩充） | 「源流 · 形制 · 工巧 · 符号 · 守望」五段长文 + 6 图以上，参考新闻报道撰写 |
| 匠人传记 | 每门类 1 位（10 位） | 生平图文传记 + 时间轴 + 作品图版 |
| 档案词条 | 其余全部项目 | 名片信息 + 五式图版 + 官方简介尽录 + 子项一览 + 承上启下导航 |

档案词条为**开放词条**：欢迎按深度专题的体例继续补充撰写。

## 六、如何浏览 { #如何浏览 }

- 首页看十大门类气泡 → 点开即达门类导航页；
- 门类页里有：**子类气泡**（如传统技艺的「陶瓷烧造」「织染绣造」）、**代表专题**、**代表人物**、**项目名录**；
- 任意词条页顶部有分类栏目，底部有上下条目与回目录链接；
- 顶部搜索框支持全文检索（含中文分词）。

## 七、来源与致谢

- 名录与项目简介：国务院公布文件、中国非物质文化遗产网（ihchina.cn）；
- 专题长文与匠人传记：综合公开新闻报道、地方志、机构官网及学术资料撰写，文末标注参考来源；
- 图版与站点设计：非遗志编辑部自绘。

## 八、本地运行与编辑

```bash
# 方式一：双击 serve.bat（Windows）
# 方式二：命令行
.venv\Scripts\python.exe -m mkdocs serve --dev-addr 127.0.0.1:8000
```

- 内容在 `docs/` 目录，纯 Markdown，改完即自动刷新；
- 名录数据在 `data/projects.json`，重新生成页面：`python tools/gen_pages.py`；重新绘制图版：`python tools/build_images.py`；
- 更多说明见项目根目录 `README.md`。
