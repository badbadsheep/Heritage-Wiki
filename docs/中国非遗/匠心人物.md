# 匠心人物 · 十位传灯人

<p class="lede">十个门类，各择一位代表立传：或名动天下，或隐于乡野；有人一出手就是国家礼品，有人一辈子没离开过一个村庄。他们把一件小事做到了极致——「匠心」二字，写在他们的手上，也写在时间里。</p>
