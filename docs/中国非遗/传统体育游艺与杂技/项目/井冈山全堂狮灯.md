## 项目简介

<p>井冈山全堂狮灯，俗称“全堂狮子”，是集多项民间武艺于一体的健身游艺项目。江西省井冈山市东上乡虎爪坪村是全堂狮灯的发源地，主要流布区域为井冈山市的虎爪坪村、东上村、河桥村、石洲村等村寨。</p>

<p>井冈山全堂狮灯自清道光年间流传，既有武术套路又有器械比武，表演步法、手法和队形纷繁奇异，变幻无穷，展现了传统民间游艺风貌。井冈山全堂狮灯还配以锣鼓、唢呐等乐器助阵，气氛热烈。</p>

<p>井冈山全堂狮灯由16人演练，由龙灯、舞狮、拳术、棍术、器械、对练以及盾牌舞等七大项目组成。龙灯，俗称“三节龙”，用竹蔑扎制、彩布连接，由3人表演完成一朝天、二朝祖、左青龙、右白虎、倒五向、舞四方等步法和要领，要求舞得圆、滚得活。舞狮，为单人手摇狮，由1人表演，主要环节有狮子下山、争抢龙门、一团和气及照古井；动作则有吃蛇、捉蚤、狮睡、擦痒和现爪等；内容包括踩少字、望月、朝五岳、跳龙门、踩八卦、捞月、打滚。拳术套路表演，即十套不同拳法。棍术套路表演，即十套不同棍法。对练，包括拳术对打和棍术对练。器械，包括关刀、双刀、铁尺、铁鞭、钩镰、钯头和板凳。盾牌舞，由10人分两组对峙表演，有莲花阵、人字阵、长蛇阵、一字阵、二字阵、万字阵、龙门阵、围困阵、收兵回朝和两国统一等10个布阵回合。</p>

<p>井冈山全堂狮灯集古朴、原始，融战斗和舞蹈于一体，把攻防格斗与健身娱乐有机融合，运用多种表演步法、手法和队形调度。拳术舒展灵活、猛劈硬挂、翻滚跌扑、变幻莫测；棍术左挡右推、上劈下戳、左旋右转；器械可劈、可刺、可砍，势如猛虎，趣味十足；龙灯滚得圆、舞得活、首尾相应、协调一致；舞狮环绕扑、窜、跳、滚，表现狮子威猛的特点；盾牌舞勇猛快进、气势逼人、刚劲有力、步伐机灵，做到“心、眼、手”快，掌声如风、出手如电。</p>

<p>井冈山全堂狮灯主要通过师徒传授和家族传承，此外在当地社群也自发地进行着集体传承。平时作为习武健身项目，每逢新春佳节，村民都会自发组织全堂狮灯闹新春、闹元宵的游艺活动。</p>

<p>井冈山全堂狮灯既是民间体育项目，同时又是民众游艺项目，它以武术为基础，以娱乐和强身健体为目的，既活跃了乡村文化生活，又可陶冶情操，具有较高的社会文化价值，对增强社区认同感和凝聚力具有积极作用。</p>
