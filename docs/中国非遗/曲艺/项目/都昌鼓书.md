## 项目简介

<p>都昌鼓书是形成并主要流行于江西省都昌县的一种曲艺“小书”形式，俗称“唱传”，百姓亦称之为“说书”。它源于宋代都昌的书院讲学之风和明代演述传奇故事的“讲传”表演，后吸收都昌文词戏、采茶戏及江西道情等艺术元素，逐步发展而成，形成至今已有1500余年的历史。如今除都昌县外，在周边的湖口、彭泽、鄱阳、景德镇、乐平等县市也很流行。</p>

<p>演唱都昌鼓书的多为盲艺人。他们左手打板，右手击鼓；夹板打节奏，鼓点造气氛。有时还以夹板当象征性道具使用，用激越的鼓点和变化的板声，模状各种声响效果，渲染书场气氛；用声、鼓、板的抑扬顿挫塑造人物性格，有很强的感染力。其书词多为七字句，有双句押韵，也有一、二、四句押韵；唱腔为板腔体，常用板式有“散板”“正板”“八板”“数板”等；基本曲调有“迈腔”“散花调”“火攻二行”“数板头”等，定调为5-2弦。它的演唱形式分为两种：一种是坐堂演唱，三人以上，其中一人演唱，三至五人分持大鼓、锣伴奏，多用于红白喜事；一种是单人演唱，用小鼓和夹板伴奏，多站立说唱，场所不拘。</p>

<p>其节目以中长篇为主，内容广泛，既有历史故事，也有当代生活。传统书目有《三国》《隋唐演义》《杨家将》等，现代书目有《怕老婆》《劝世人》《新旧婚姻对比》等。曲本大都具有传奇色彩，情节曲折，扣人心弦，群众喜闻乐见。表演时，以唱带说，绘声绘色，引人入胜。都昌鼓书传承方式以师徒传承为主，亦有艺人自学成才。</p>

<p>都昌鼓书是一种稀珍的民间曲艺形式，有深远的历史价值。其表现形式独特，一唱众和，具有多变的击鼓技艺和声情并茂的塑造手段，有较高的艺术价值。其内容丰富，以传统书目为主，具有厚重的民族文化价值。它源于民间，流传广泛，对弘扬优秀传统文化、坚定文化自信有促进作用，有着很高的社会与学术价值。</p>
