## 项目简介

<p>“撒叶儿嗬”，意为“跳丧、打丧鼓、跳丧鼓”，是湖北西部清江流域土家族传统歌舞，历史悠久。主要流布于湖北省清江流域中游地区的土家族村寨，盛行于湖北省宜昌市五峰土家族自治县、长阳土家族自治县和恩施土家族苗族自治州巴东县的大部分区域。</p>

<p>清江土家族为古代五姓巴人廪君蛮后裔，崇拜白虎。唐《蛮书》载，“巴氏祭其祖，击鼓而祭，白虎之后也。击鼓以道哀，其歌必号，其众必跳。”清《长乐县志》载：“家有亲丧，乡邻来吊，至夜不去，曰伴亡。于柩旁击鼓，互唱俚歌……”。廪君蛮发祥地的清江土家族现仍沿袭先祖风习。</p>

<p>五峰土家族“撒叶儿嗬”是一种仪式歌舞。土家族认为人的生死有如春夏秋冬四季变化，是自然而然的，享尽天年的老人辞世是顺应自然规律，值得庆贺。在大山深处的土家村寨，听到报信的三眼铳响，乡亲们便赶往孝家“看信”。“人死众家丧，一打丧鼓二帮忙。打不起豆腐送不起情，跳一夜丧鼓送人情。”聚在孝家堂屋里亡者灵柩前，男人载歌载舞，女人穿戴鲜亮服饰围观助兴，通宵达旦，以绝妙的歌腔舞态表达对生命的赞颂、对人与自然关系的认知和旷达的生死观。</p>

<p>跳“撒叶儿嗬”时由歌师击鼓叫歌，核心舞段鼓点为民歌体裁中罕见的6/8拍子带切分音节奏律动，兼有2/4、4/4与6/8杂糅节奏混合转换。舞者应节起舞，舞姿呈顺、曲、颤特征。舞蹈风格有文、武之分：文场有跑场子、滚身子等20种基本套路，古朴优雅、刚柔相济；武场有猛虎下山等8种套路，动作强健刚劲，虎虎生风。</p>

<p>五峰土家族“撒叶儿嗬”是当地土家族民众都可参与的民俗活动，以村落群体传承方式相沿成习，有广泛的群众基础，存续状态良好。</p>

<p>五峰土家族“撒叶儿嗬”是歌、舞、乐浑然一体的艺术。其声腔以男嗓高八度颤音运腔，歌调是一种古老的特性三度，曲体结构有古代巴楚之地祭神乐歌的遗韵，所唱五句子情歌体裁独特，具有较高的历史和艺术价值。与此同时，该遗产项目表达了土家族特有的风俗观念、豁达通脱的生命意识、因循自然的朴素哲学思想以及乡邻族群亲睦的积极人生态度，具有较高的文化和社会价值。</p>
